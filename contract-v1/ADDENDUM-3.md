# 追加ブリーフ 3：メーターと状態ドットをファーストリリースから削除（2026-11-21、カイル）

## 背景

ユーザーの決定：ファーストリリース（v1）に中途半端な表示を載せない。メーターとサービスの状態ドットは v1 の画面から削除する。どちらも将来のブロック（メーター収集／状態プロバイダ接続）で復活させる前提で、土台は残す。

## 仕様

1. **メーター表示の削除**
   - ポータルのデバイスカードから、メーター表示（メモリ／ディスクのパーセンテージ表示と「未取得」表示）を削除する。
   - 管理画面にメーター関連の表示や入力が残っていれば、それも削除する。
   - `GET /api/devices/:id/meters` の API 自体は将来の収集ブロックのために残してよい（v1 では未使用でよい）。
   - 台帳の SSH 関連列（ssh_user / ssh_port 等）は削除しない。
2. **状態ドットの削除**
   - サービスの状態ドット表示を GUI から削除する。凡例やプレースホルダなど、状態表示の名残があれば含む。
   - API は既に `status` を返していないはずだが、返している箇所があれば v1 では外す。
   - 状態プロバイダの差し込み設計自体は維持する（未接続時に何も出さない現行仕様のまま）。
3. **テスト**
   - 削除に伴い不要になったテストは整理し、残りが全件成功すること。
   - スクリーンショット検証の状態数などに影響があれば、報告に明記する。

## 報告

- 結果をプロジェクトの `報告書.md` に追記すること。
- 成果物は `成果物/v1/` へ同期すること。

# 追加ブリーフ 7 補足4：VM 関係は同じネットワークの中だけに張る（2026-11-21、カイル）

## 背景

GitHub Pages デモ用サンプルデータについて、ユーザーから追加の指定があった。狙いは「ユーザーの認知負荷を減らしつつ、関係機能のすごさをアピールする」こと。関係線がネットワークをまたぐと追いにくいので、デモではネットワークの中に収める。

## 仕様

1. **対象はデモのサンプルデータのみ**（製品仕様の変更ではない）。
2. VM とその VM ホストは、**同じネットワークに所属**させる。ホストが複数ネットワークに所属している場合は、VM と同じネットワークに所属していることが分かる形にする。
3. 関係は**同一ネットワーク内の VM ↔ ホストのペアだけ**に張る。ネットワークをまたぐ関係は作らない。既存のサンプルデータにまたぐ関係があれば、所属を寄せるか関係を組み替えて解消する。
4. 補足3の限定（関係は VM と VM ホストの間だけ）は維持する。
5. デバイス・サービスの構成は大きく変えない（VM の所属ネットワークの付け替えは可）。
6. サンプル YAML を更新し、形式バリデーションを通すこと。デモを再ビルドし、`成果物/demo-pages/` へ再同期する。

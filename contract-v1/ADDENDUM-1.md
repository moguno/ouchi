# 追加ブリーフ 1：設定のテキストエクスポート／インポート（2026-11-21、カイル）

v1 実装の起動後に届いた追加仕様。本文（README.md）の §7 として統合済み。要点だけ再掲する。

- 台帳一式を **YAML** でエクスポート／インポートできるようにする（`GET /api/export`、`POST /api/import`、管理画面に導線）
- 参照は内部 ID ではなく自然キー（ネットワーク名・ホスト名・subdomain）で持つ
- インポートは全件バリデーションを通してから、トランザクションで**全置き換え**。不正なら何も変えない
- 目的はバージョンアップ時のデータ移行（旧版エクスポート → 新版インポートを正道にする）
- 検収：ラウンドトリップ一致、不正時に DB 無変更、ID が振り直されても名前で再構成されること

現行の実装タスクに取り込めるなら取り込むこと。難しい場合は無理に混ぜず、完了報告に「追加分の対応状況」を書くこと（続けて別タスクで投げる）。

# 追加ブリーフ 7 補足 6：デモのネットワーク再編（2026-11-21、カイル）

## 内容

デモサイト（サンプルデータ）のネットワーク構成を変更する。ユーザー指示。対象は**デモのサンプルデータのみ**。

## 変更内容

1. デバイス `aura-gw` の名前を **`l3-switch`** に変更する（カテゴリはネットワーク機器のまま）。自然キー参照（所属・サービス等）はすべて追随させる。
2. `l3-switch`（旧 aura-gw）の **インターネット ネットワークへの所属を削除**する。家族用LAN・ホームラボへの所属は残す。
3. 新しいネットワーク **個人ネットワーク** を作成し、`l3-switch` を所属させる。
4. 個人ネットワークに、次の新規デバイスを追加する：
   - ネットワーク機器 **l2-switch**（1台）
   - 物理マシン 1台（名称は既存の命名スタイルに合わせた架空名を Codex が付けて報告に明記）
   - VM 2台（同上、isVm=true）

## 仕様

1. 新規 VM 2台は、既存のデモ方針（関係は VM↔VMホストのみ・同一ネットワーク内）に沿って、新規物理マシンをホストとする関係を張る。
2. 個人ネットワークのアドレス帯は、既存3帯域（192.0.2.0/24、198.51.100.0/24、203.0.113.0/24）と重ならない架空の帯域を Codex が選び、各デバイスに IP を割り当て、報告書に明記すること。
3. 台帳の実データ（API モード用シード等）には手を入れない。
4. 検証（verify／テスト）を通し、デモを再ビルドして `成果物/demo-pages/` に同期すること。`成果物/v1/` 側にもサンプルが含まれる場合はそちらも同期する。

## 報告

- 結果をプロジェクトの `報告書.md` に追記すること（変更・追加の一覧、新規デバイス名、個人ネットワークのアドレス帯、参照追随の確認方法）。

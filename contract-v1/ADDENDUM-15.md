# 追加ブリーフ 15：デモモードでサービスタイルを押したらアラート（2026-11-21、カイル）

## 内容

デモモード（YAML 読み取り専用の表示専用デモ）では、サービスタイルをクリックしても実際の URL へはジャンプせず、アラートを表示する。ユーザー指示。

## 仕様

1. **対象**：デモモードのポータル表示にあるサービスタイルのクリック。
2. **動作**：ジャンプせず、アラートで次の文言を**正確に**表示する：
   > ここをクリックすると設定したURLにジャンプします
   - URL が未設定のサービスでも同じアラートにする。
   - 表示方法はアプリ内ダイアログ（既存デザインに合わせる）でよい。ブラウザ標準の alert() でも可だが、デザインに合う方を優先する。
3. **通常モード（API モード）は変更しない**：サービスタイルは従来どおり設定した URL へジャンプする。
4. 再ビルドし、`成果物/v1/` と `成果物/demo-pages/` に同期する。

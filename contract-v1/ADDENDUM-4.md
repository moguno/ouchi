# 追加ブリーフ 4：Apache-2.0 ライセンスの適用（2026-11-21、カイル）

## 背景

ユーザーの決定：ouchi.local のライセンスは **Apache-2.0**。GitHub で正しく認識される形で適用する。

## 仕様

1. **LICENSE ファイル**：`contract-v1/LICENSE`（Apache 公式テキスト、著作権行のみ `Copyright 2026 moguno` を記入済み）を、**内容を改変せずに**リポジトリ直下へコピーする。GitHub のライセンス検出（Licensee）が Apache-2.0 と認識する標準形式なので、文面には手を入れないこと。
2. **package.json**：`"license": "Apache-2.0"`（SPDX 識別子）を設定する。成果物の npm パッケージにも LICENSE が含まれることを確認する。
3. **README**：ライセンス節を追加する（「Apache License 2.0」表記と LICENSE へのリンク）。バッジは任意。
4. **Docker イメージ／成果物**：配布物にも LICENSE を含める。依存ライブラリは permissive ライセンスのみで競合しない前提だが、作業中に競合に気づいたら報告すること。
5. **対象外**：各ソースファイルへのライセンスヘッダコメントは今回は付けない（リポジトリ直下の LICENSE で十分）。

## 報告

- 結果をプロジェクトの `報告書.md` に追記すること。
- 成果物は `成果物/v1/` へ同期すること。

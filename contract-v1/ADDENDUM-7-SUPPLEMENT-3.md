# 追加ブリーフ 7 補足3：デモデータの関係を VM と VM ホストだけに限定（2026-11-21、カイル）

## 背景

GitHub Pages デモ用サンプルデータについて、ユーザーから追加の指定があった。関係（relations）は当面シンプルに保つ。

## 仕様

1. **関係の限定**：サンプルデータの relations は、**VM とその VM ホスト（物理ホスト）の間の関係だけ**にする。
2. それ以外の関係（バックアップ先・レプリカ等の味付け関係）は、既存分・補足2で追加された分を含め、**全て削除**する。
3. 方向ラベルは既存の流儀を維持する（ホスト側「VMホスト」、VM 側「親ホスト」など）。
4. デバイス・サービス・ネットワークの構成は変更しない（データのうち relations だけの変更）。
5. サンプル YAML を更新し、形式バリデーションを通すこと。デモを再ビルドし、`成果物/demo-pages/` へ再同期する。

- 残った関係の一覧（from → to、ラベル）を報告に書くこと。

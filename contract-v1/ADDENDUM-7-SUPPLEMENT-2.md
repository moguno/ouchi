# 追加ブリーフ 7 補足2：サンプルデータに物理マシンを追加（2026-11-21、カイル）

## 背景

ADDENDUM-7 補足で作った GitHub Pages デモ用サンプルデータについて、ユーザーから追加の指定があった。ポータルの見栄えを厚くするため、物理マシンを増やす。

## 仕様

1. **物理マシンの追加**：内部ネットワーク2つ（自宅 LAN／サーバーセグメント）に、物理マシン（category: physical）を**各4台追加**する。既存のデバイス（cedar-host 等）は残す。
2. 追加分は架空のホスト名にし、IP は各ネットワークの TEST-NET 帯域内で、既存と重複しない値を割り当てる。
3. 追加した物理マシンには、それぞれサービスを1件以上付ける（架空のサービスでよい）。関係（バックアップ先・レプリカ等）は、見栄えのために何件か張ってよい（任意）。
4. サンプル YAML を更新し、実装済みの形式バリデーションを通すこと。デモを再ビルドし、`成果物/demo-pages/` へ再同期する。
5. YAML モードや表示側のコードは変更しない（データだけの変更）。

## 報告

- 結果をプロジェクトの `報告書.md` に追記すること。
- 追加後のデバイス総数と、ネットワークごとの物理マシン台数を報告に書くこと。

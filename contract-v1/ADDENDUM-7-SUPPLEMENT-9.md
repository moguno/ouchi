# 追加ブリーフ 7 補足 9：関係ラベルの統一と色の統一（2026-11-21、カイル）

## 内容

デモサイト（サンプルデータ）の関係（VM↔ホスト）のラベルと色を統一する。ユーザー指示。対象は**デモのサンプルデータのみ**。

## 現状（サンプル YAML で確認済み）

関係 5 件すべてが `tag: VM`、`fromLabel: VMホスト`、`toLabel: 親ホスト` で、色だけが 5 件すべて異なる（#d48a2f / #4d9b78 / #8a67c7 / #3f83a8 / #b95f8a）。

## 変更内容

1. 方向ラベルを統一する：
   - ホスト側のラベル（fromLabel）: `VMホスト` → **親ホスト**
   - VM 側のラベル（toLabel）: `親ホスト` → **VM**
   - 関係ラベルから `VMホスト` をなくす。tag は `VM` のまま。
2. 色を統一する：同じ tag（VM）の関係 5 件すべての色を、cedar-host → harbor-core の現行色 **`#d48a2f`** に揃える。
3. メンバーシップ側のラベル（cedar-host / akari の所属ラベル `VMホスト`）は今回の対象外で、変更しない。

## 仕様

- 台帳の実データ（API モード用シード等）には手を入れない。
- 検証（verify／テスト）を通し、デモを再ビルドして `成果物/demo-pages/` に同期すること。`成果物/v1/` 側にもサンプルが含まれる場合はそちらも同期する。

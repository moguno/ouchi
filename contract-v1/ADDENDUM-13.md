# 追加ブリーフ 13：接続点を辺ごとに本数応じて自動振り分け（2026-11-21、カイル）

## 背景

追加ブリーフ12で接続点の規則（相手が上→上辺、下→下辺、同じライン→左右辺）が確定した。現状は各辺に接続点が1つ（中央）だけなので、1つの辺に複数のリンクが集まるカード（例：cedar-host の下辺に VM 3台へのリンク）では、全線が1点から扇状に出て重なる。ユーザー決定により、**辺を使うリンクの本数に応じて接続点を自動で振り分ける**。

## 仕様

1. **振り分け**：あるカードのある辺を使うリンクが n 本ある場合、その辺の上に n 個の接続点を均等に配置する。
   - n=1 のときは従来どおり辺の中央に1点（見た目を変えない）。
   - 配置間隔の具体式（例：辺を n+1 等分した位置）は実装側で決め、報告書に明記すること。カードの角に寄りすぎないこと。
2. **割り当て順**：交差を避けるため、相手の並び順に割り当てる。
   - 上辺・下辺：相手カードの中心 x の昇順に、点を左から右へ割り当てる。
   - 左辺・右辺：相手カードの中心 y の昇順に、点を上から下へ割り当てる。
3. **両端それぞれ**：各カードが自分の辺について独立に同じ振り分けを行う（相手側の点の位置は相手側の事情で決まる）。
4. **維持するもの**：追加ブリーフ12の規則（辺の選び方、線分は独立描画、カード内側は描かない）、最前面の Z オーダー、ツールチップは線より前面、ドットの見た目（大きさ・色＝関係の色）、選択ハイライト。

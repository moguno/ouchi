# 追加ブリーフ 2：ポータルタイトルを設定値にする（2026-11-21、カイル）

## 背景

現行実装ではポータルタイトル「あなたのホームラボ」の保存先が settings になく、セッション内の表示設定に留まっている。ユーザーの決定により、**管理画面から変更できる設定値**にする。

## 仕様

1. **DB**：`settings` に列を追加する。
   - `title TEXT NOT NULL DEFAULT 'あなたのホームラボ'`
   - `contract-v1/schema.sql` と `seed.sql` を更新する（seed の settings 行には title を明示する）。
   - 既存 DB の移行はエクスポート→インポートが前提なので、自動マイグレーション（ALTER）は実装しない。
2. **API**：
   - `GET /api/settings` / `PUT /api/settings` に `title` を含める。
   - `GET /api/portal` の settings にも `title` を含める。
   - バリデーション：空文字は不可（400）。長さ上限は 100 文字。改行は不可。
3. **GUI**：
   - 管理画面の設定欄に「ポータルタイトル」のテキスト入力を追加する（domain と並べる）。
   - ポータルのタイトル表示は `settings.title` を使う。セッション内だけの表示設定は廃止し、保存は API 経由のみにする。
4. **エクスポート／インポート**（追加ブリーフ 1 の続き）：
   - YAML に `settings`（`domain` と `title`）を含める。まだ含んでいなければ追加する。
   - 往復一致の確認対象に `title` を含める。
5. **対象外**：サブタイトル（開くたびに交互表示される文言）は今回触らない。現状のまま。

## 検収条件

- 管理画面でタイトルを変更し、リロードしても保持される。
- エクスポート→インポートの往復で `title` が一致する。
- 空文字などの不正値では 400 になり、DB が変わらない。
- 既存テストが全件成功し、title の読み書きテストが追加されている。

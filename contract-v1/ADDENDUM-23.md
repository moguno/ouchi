# ADDENDUM-23: 管理画面の全画面化とタブ構成の見直し

v1 本体への GUI 改善。管理画面を右ドロワーから全画面ビューに変え、
タブ構成を5つに整理する。API・DB・YAML 形式は変更しない。

## 背景

- 現行の管理画面は画面右半分ほどのドロワーで、上部に共通設定
  （ポータルのタイトル、YAML エクスポート／インポート）が常駐し、
  その下に ネットワーク／デバイス／サービス の3タブがある。
- 狭くて腰を据えた編集に向かない。共通設定が常時場所を取る。
  関係（relations）はデバイス編集の中にしか導線がなく、全体を
  見渡せない。

## 実装内容

### 全画面化

- ポータルの「管理」ボタンで、全画面の管理ビューに切り替える。
  SPA 内のビュー遷移とし、ページリロードはしない。
- 管理ビューに「ポータルに戻る」導線を置き、戻るとポータルの
  表示状態（選択中のデバイス等）を保持していること。
- タブは管理ビュー上部に置き、コンテンツは画面幅いっぱいに使う。
  各エンティティの一覧はドロワー時代の幅に縛られないこと。

### タブ構成（5つ）

1. ネットワーク（件数バッジ付き、現行踏襲）
2. デバイス（同上）
3. サービス（同上）
4. 関係
5. 共通設定

既定で開くタブは ネットワーク。

### 関係タブ（新設）

- 全関係を一覧する：元デバイス → 先デバイス、タグ（色チップ）、
  方向ラベル（fromLabel / toLabel）。
- 追加・編集・削除ができる。編集ダイアログはデバイス編集内の
  関係編集と**同じコンポーネントを共用**し、デバイス側の導線は
  現行どおり残す（入口2つ、ダイアログ1つ）。
- タグ単位の色変更をこのタブに置く（同じタグ＝同じ色のルールに
  基づき、既存 API のタグ色一括更新を使う）。

### 共通設定タブ（新設）

- 現行ドロワー上部の2ブロックをそのまま移す：
  - ポータルのタイトル（ドメイン、ポータルタイトル、保存ボタン）
  - 設定のエクスポート／インポート（YAML エクスポートボタン、
    インポート用ファイル選択、全量置換の注意書きを含む現行の文言）
- 動作・検証は現行と同一に保つ。

### エンティティ系タブ

- ネットワーク／デバイス／サービスの各タブは、現行の一覧・追加・
  編集・削除の動作をそのまま全画面レイアウトに移す。
- 編集ダイアログ自体の項目・検証は変更しない（プロパティ編集を
  含む）。

## 制約

- API、DB スキーマ、YAML 形式、MCP は一切変更しない。GUI のみの変更。
- デモモード（YAML データソース、読み取り専用）の挙動は現行どおり
  （管理は使えない）。
- 既存テストは全件パスさせる。タブ切り替え、関係タブの一覧・編集、
  共通設定タブのタイトル保存とエクスポート／インポートについて
  GUI テストを追加・調整する。
- README に管理画面の説明があれば、全画面＋5タブ構成に合わせて更新する。
- 結果を 報告書.md に追記する。

## 検収条件

- 管理ボタンで全画面の管理ビューに遷移し、5タブが切り替わる。
- 関係タブで全関係の一覧・追加・編集・削除とタグ色変更ができる。
  デバイス編集内の関係編集も従来どおり動く。
- 共通設定タブでタイトル保存と YAML エクスポート／インポートが
  従来どおり動く。
- ポータルに戻ると表示状態が保持されている。
- 既存テスト全件パス＋新規 GUI テスト。
- 実ブラウザでの見た目はカイル側でスクリーンショット検収する
  （Codex のサンドボックスで Playwright が動かない場合は、その旨を
  報告書に明記すればよい）。

## 範囲外

- エンティティ編集ダイアログの項目追加・変更。
- 一覧と編集フォームの並列表示（マスター・ディテール化）は今回の
  必須ではない。全画面化の土台だけを作る。
